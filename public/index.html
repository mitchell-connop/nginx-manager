📹 Add RTSP Stream

    

      A TCP proxy in nginx's stream context (separate from http, so it lives in , included from
      ). Clients connect to rtsp://<this server>:<listen>/<camera path> — the path
      and any camera login pass straight through. Clients must use RTSP over TCP (ffmpeg -rtsp_transport tcp,
      VLC "RTP over RTSP (TCP)"); UDP media can't be proxied.
    

    

      

      

        
Use a distinct port per camera (8554, 8555, …).

    

    

      

        
Port defaults to 554.

      

        
Only used while the camera is unreachable.

    

    

      
      
IPs or CIDRs allowed to watch; everyone else is refused. Cameras rarely have strong auth — keep this tight (0.0.0.0/0 allows everyone).

    

      

      

        
Closes a session after this long with no data either way.

Install the nginx-manager helper

    

      Run as root on each nginx server. It installs a small Python service (nginx-manager-helper, no extra packages)
      that runs unprivileged, probes the backends listed in helper.json, reads the loopback-only stub_status, and reports to
      this manager over the same UDP port as the request log. Its target list is delivered through NGINX Agent, so config changes never need a reinstall.
